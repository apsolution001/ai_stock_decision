## Milestones

- **M1: CLI analysis** (after phase 4). `python -m app.cli analyze RELIANCE` prints the decision along with its evidence.
- **M2: Service** (after phase 5). Scheduled NIFTY 50 scans are stored in Postgres and served over the API.
- **M3: Product** (after phase 6). The dashboard is usable end to end.
- **M4: Trustworthy** (after phase 7). The confidence threshold is backed by measured accuracy.

## Key risks

- **Laya zero-shot accuracy is near chance (~0.36).** Mitigations: the confidence gate, the `NO_CALL` status, and phase 7 fine-tuning. Pulling part of phase 7 (golden-set labeling) forward to run in parallel with phases 3–4 is a good option.
- **Free data sources (yfinance, RSS) are unofficial.** The provider protocols keep them swappable for NSE or broker APIs.
- **The ~808 MB checkpoint is downloaded on first load.** It is cached in a Docker volume, and `HF_HUB_OFFLINE=1` is used in production.
