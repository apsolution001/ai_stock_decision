# Foundation Implementation Plan (INDstocks auto-trader)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A runnable, tested Python backend skeleton with the pure core every later step builds on: IST clock, charges model, validated safety config, and the indicators the three candidate strategies need.

**Architecture:** One `uv` project at the repo root; the Python package `app` lives in `backend/app` (per `docs/standards/coding-standards.md` layout). Everything in this plan is pure or near-pure and needs no network, broker, database or UI. It deliberately contains nothing that depends on the still-unapproved design sections (broker, engine, risk manager, UI).

**Tech Stack:** Python 3.11, uv, FastAPI, pydantic v2 + pydantic-settings, pandas, numpy, tzdata, pytest, httpx, ruff, mypy (strict), GitHub Actions.

**Spec:** No approved spec yet for the new design. Binding sources instead: `docs/research/07-decisions-log.md` (decisions D1–D17), `docs/standards/trading-safety-rules.md`, `docs/standards/coding-standards.md`, `docs/standards/testing-standards.md`, `docs/research/06-costs-and-math.md`, `docs/research/03-strategies.md`.

## Global Constraints

- Python `>=3.11`, managed by `uv` with a committed `uv.lock`; `pyproject.toml` is at the repo root; package code in `backend/app`, tests in `backend/tests`.
- Money is `Decimal`, never float; quantities are `int`. Floats only inside indicator maths.
- Time is tz-aware IST (`Asia/Kolkata`). Only `app/core/clock.py` may call `datetime.now`. Never call `datetime.now()` / `datetime.utcnow()` / `date.today()` anywhere else.
- Candle frames: pandas `DataFrame` with columns `open, high, low, close, volume` and a tz-aware `Asia/Kolkata` `DatetimeIndex` where each timestamp is the bar's **start** time.
- Config env var names have **no prefix** and match `trading-safety-rules.md` (e.g. `TRADING_MODE`, `LIVE_CONFIRM`, `MAX_TRADES_PER_DAY`). `TRADING_MODE` defaults to `paper`.
- **Never** set `TRADING_MODE=live` in a way that is accepted, never write the real `LIVE_CONFIRM` value into any test/command, never read or print `.env`, never place orders. Tests may only assert that live mode is **refused**.
- Tests are hermetic: no network, no reading a real `.env`, not affected by the developer's shell env.
- Before every commit run, from the repo root: `uv run ruff format .`, `uv run ruff check .`, `uv run mypy backend/app`, `uv run pytest` — all must pass.
- Conventional commits; work on branch `feat/foundation`, never on `main`.
- Files stay under ~300 lines, one responsibility each. Comments explain *why*.

## Review Focus

- A developer's shell has `TRADING_MODE=live` exported, or a real `.env` exists at the repo root: the test suite must be unaffected and must never load it (conftest in Task 1, extended in Task 4).
- Candles with a naive or UTC index passed to session indicators (VWAP, opening range, slot volume): must raise `ValueError`, never silently group by the wrong calendar day (Task 6 tests).
- Look-ahead: an indicator value at bar *t* must not change when bars after *t* change (Task 5 and Task 6 tests).
- Zero volume (first bar of a session, or an average of zero): result is `NaN`, never `inf` or a `ZeroDivisionError` (Task 6 tests).
- A float price or a non-positive quantity reaching the charges model: must raise, never silently compute money in float (Task 3 tests).

```python
"""The only place allowed to read the wall clock.

Everything else calls `now()` so tests can inject time.
"""

from datetime import datetime, timedelta
from typing import Protocol
from zoneinfo import ZoneInfo

IST = ZoneInfo("Asia/Kolkata")


class Clock(Protocol):
    def now(self) -> datetime: ...


def to_ist(dt: datetime) -> datetime:
    if dt.tzinfo is None or dt.utcoffset() is None:
        raise ValueError(f"naive datetime not allowed: {dt!r}")
    return dt.astimezone(IST)


class SystemClock:
    def now(self) -> datetime:
        return datetime.now(IST)


class FixedClock:
    def __init__(self, at: datetime) -> None:
        self._at = to_ist(at)

    def now(self) -> datetime:
        return self._at

    def advance(self, delta: timedelta) -> None:
        self._at = self._at + delta


_clock: Clock = SystemClock()


def set_clock(clock: Clock) -> None:
    global _clock
    _clock = clock


def now() -> datetime:
    return _clock.now()
```

- Produces: `order_charges(side: Side, product: Product, price: Decimal, quantity: int, rates: ChargeRates) -> ChargeBreakdown` and `round_trip_charges(product: Product, entry_price: Decimal, exit_price: Decimal, quantity: int, rates: ChargeRates) -> ChargeBreakdown` (long only: BUY at entry, SELL at exit).
- Task 4's `Settings` builds a `ChargeRates` from config using these exact field names.

Rules (from `docs/research/06-costs-and-math.md`): brokerage flat per order; STT intraday on sell only, delivery on buy and sell; exchange txn on turnover both sides; SEBI `sebi_per_crore` per ₹1 crore of turnover both sides; stamp on buy only; GST = `gst_pct` of (brokerage + exchange + SEBI), computed on the **unrounded** components; DP charge on delivery sells only. Each component is rounded to paise with `ROUND_HALF_UP` once, at the end; `total` is the sum of rounded components. Defaults are the research values and carry a "verify before live" note; the DP default is `0` because the INDstocks DP charge is unknown (research/06 ⚠️).

```python
"""Per-order NSE equity charges. Rates: docs/research/06-costs-and-math.md.

Default rates are the standard NSE rates as understood in research/06 and MUST be verified against
INDstocks' official charges page before live mode; the live values come from config (Settings).
"""

from dataclasses import dataclass, fields
from decimal import ROUND_HALF_UP, Decimal
from enum import StrEnum

PAISE = Decimal("0.01")
HUNDRED = Decimal("100")
CRORE = Decimal("10000000")


class Side(StrEnum):
    BUY = "BUY"
    SELL = "SELL"


class Product(StrEnum):
    INTRADAY = "INTRADAY"
    DELIVERY = "DELIVERY"


@dataclass(frozen=True)
class ChargeRates:
    brokerage_per_order: Decimal = Decimal("10")
    stt_intraday_sell_pct: Decimal = Decimal("0.025")
    stt_delivery_pct: Decimal = Decimal("0.1")
    exchange_txn_pct: Decimal = Decimal("0.00297")
    sebi_per_crore: Decimal = Decimal("10")
    stamp_intraday_buy_pct: Decimal = Decimal("0.003")
    stamp_delivery_buy_pct: Decimal = Decimal("0.015")
    gst_pct: Decimal = Decimal("18")
    # INDstocks DP charge is unknown (research/06); 0 understates swing costs until verified.
    dp_charge_per_sell: Decimal = Decimal("0")


@dataclass(frozen=True)
class ChargeBreakdown:
    brokerage: Decimal
    stt: Decimal
    exchange_txn: Decimal
    sebi: Decimal
    stamp: Decimal
    gst: Decimal
    dp: Decimal

    @property
    def total(self) -> Decimal:
        return sum((getattr(self, f.name) for f in fields(self)), Decimal("0"))

    def __add__(self, other: "ChargeBreakdown") -> "ChargeBreakdown":
        return ChargeBreakdown(
            **{f.name: getattr(self, f.name) + getattr(other, f.name) for f in fields(self)}
        )


def _paise(amount: Decimal) -> Decimal:
    return amount.quantize(PAISE, rounding=ROUND_HALF_UP)


def order_charges(
    side: Side, product: Product, price: Decimal, quantity: int, rates: ChargeRates
) -> ChargeBreakdown:
    if not isinstance(price, Decimal):
        raise TypeError(f"price must be Decimal, got {type(price).__name__}")
    if price <= 0:
        raise ValueError(f"price must be positive, got {price}")
    if quantity <= 0:
        raise ValueError(f"quantity must be positive, got {quantity}")

    turnover = price * quantity
    is_buy = side is Side.BUY
    intraday = product is Product.INTRADAY

    if intraday:
        stt_pct = Decimal("0") if is_buy else rates.stt_intraday_sell_pct
        stamp_pct = rates.stamp_intraday_buy_pct if is_buy else Decimal("0")
    else:
        stt_pct = rates.stt_delivery_pct
        stamp_pct = rates.stamp_delivery_buy_pct if is_buy else Decimal("0")

    brokerage = rates.brokerage_per_order
    exchange_txn = turnover * rates.exchange_txn_pct / HUNDRED
    sebi = turnover * rates.sebi_per_crore / CRORE
    # GST is levied on the unrounded service components, then the result is rounded once.
    gst = (brokerage + exchange_txn + sebi) * rates.gst_pct / HUNDRED
    dp = rates.dp_charge_per_sell if (not intraday and not is_buy) else Decimal("0")

    return ChargeBreakdown(
        brokerage=_paise(brokerage),
        stt=_paise(turnover * stt_pct / HUNDRED),
        exchange_txn=_paise(exchange_txn),
        sebi=_paise(sebi),
        stamp=_paise(turnover * stamp_pct / HUNDRED),
        gst=_paise(gst),
        dp=_paise(dp),
    )


def round_trip_charges(
    product: Product,
    entry_price: Decimal,
    exit_price: Decimal,
    quantity: int,
    rates: ChargeRates,
) -> ChargeBreakdown:
    """Long-only round trip (D10): BUY at entry, SELL at exit."""
    buy = order_charges(Side.BUY, product, entry_price, quantity, rates)
    sell = order_charges(Side.SELL, product, exit_price, quantity, rates)
    return buy + sell
```

```python
import numpy as np
import pandas as pd


def ema(values: pd.Series, period: int) -> pd.Series:
    """EMA seeded with the SMA of the first `period` values (TA-Lib convention); NaN before that."""
    if period < 1:
        raise ValueError(f"period must be >= 1, got {period}")
    arr = values.to_numpy(dtype=float)
    out = np.full(len(arr), np.nan)
    if len(arr) >= period:
        alpha = 2.0 / (period + 1)
        out[period - 1] = arr[:period].mean()
        for i in range(period, len(arr)):
            out[i] = alpha * arr[i] + (1 - alpha) * out[i - 1]
    return pd.Series(out, index=values.index, name=f"ema_{period}")
```

```python
import numpy as np
import pandas as pd


def _rsi_value(avg_gain: float, avg_loss: float) -> float:
    if avg_loss == 0:
        return 50.0 if avg_gain == 0 else 100.0
    return 100.0 - 100.0 / (1.0 + avg_gain / avg_loss)


def rsi(close: pd.Series, period: int = 14) -> pd.Series:
    """Wilder's RSI. The first value is at index `period` (needs `period` price changes)."""
    if period < 1:
        raise ValueError(f"period must be >= 1, got {period}")
    arr = close.to_numpy(dtype=float)
    out = np.full(len(arr), np.nan)
    if len(arr) > period:
        delta = np.diff(arr)
        gains = np.clip(delta, 0.0, None)
        losses = np.clip(-delta, 0.0, None)
        avg_gain = float(gains[:period].mean())
        avg_loss = float(losses[:period].mean())
        out[period] = _rsi_value(avg_gain, avg_loss)
        for i in range(period + 1, len(arr)):
            avg_gain = (avg_gain * (period - 1) + float(gains[i - 1])) / period
            avg_loss = (avg_loss * (period - 1) + float(losses[i - 1])) / period
            out[i] = _rsi_value(avg_gain, avg_loss)
    return pd.Series(out, index=close.index, name=f"rsi_{period}")
```

```python
import numpy as np
import pandas as pd


def true_range(candles: pd.DataFrame) -> pd.Series:
    """True range; the first bar has no previous close, so it is NaN."""
    prev_close = candles["close"].shift(1)
    ranges = pd.concat(
        [
            candles["high"] - candles["low"],
            (candles["high"] - prev_close).abs(),
            (candles["low"] - prev_close).abs(),
        ],
        axis=1,
    )
    return ranges.max(axis=1, skipna=False).rename("true_range")


def atr(candles: pd.DataFrame, period: int = 14) -> pd.Series:
    """Wilder's ATR (TA-Lib convention): first value at index `period` = mean of TR[1..period]."""
    if period < 1:
        raise ValueError(f"period must be >= 1, got {period}")
    tr = true_range(candles).to_numpy(dtype=float)
    out = np.full(len(tr), np.nan)
    if len(tr) > period:
        out[period] = tr[1 : period + 1].mean()
        for i in range(period + 1, len(tr)):
            out[i] = (out[i - 1] * (period - 1) + tr[i]) / period
    return pd.Series(out, index=candles.index, name=f"atr_{period}")
```

```python
import numpy as np
import pandas as pd

from app.indicators.frame import require_ist_index


def session_vwap(candles: pd.DataFrame) -> pd.Series:
    """Typical-price VWAP, cumulative within each IST trading day (research/03)."""
    index = require_ist_index(candles)
    typical = (candles["high"] + candles["low"] + candles["close"]) / 3.0
    volume = candles["volume"].astype(float)
    day = index.date
    cum_pv = (typical * volume).groupby(day).cumsum()
    cum_volume = volume.groupby(day).cumsum()
    return (cum_pv / cum_volume.replace(0.0, np.nan)).rename("vwap")
```

```python
import pandas as pd

from app.indicators.frame import require_ist_index


def opening_range(
    candles: pd.DataFrame, start: time = time(9, 15), end: time = time(9, 30)
) -> pd.DataFrame:
    """Per-day high/low of bars whose start time is in [start, end) (research/03, candidate 1)."""
    index = require_ist_index(candles)
    bar_times = index.time
    in_window = (bar_times >= start) & (bar_times < end)
    window = candles[in_window]
    result: pd.DataFrame = window.groupby(index[in_window].date).agg(
        or_high=("high", "max"), or_low=("low", "min")
    )
    return result
```

```python
import numpy as np
import pandas as pd

from app.indicators.frame import require_ist_index


def slot_volume_ratio(candles: pd.DataFrame, lookback: int = 20) -> pd.Series:
    """Volume vs the same time slot's mean over the previous `lookback` days (research/03).

    shift(1) inside each slot excludes the current day, so there is no look-ahead.
    """
    if lookback < 1:
        raise ValueError(f"lookback must be >= 1, got {lookback}")
    index = require_ist_index(candles)
    volume = candles["volume"].astype(float)
    slot_mean = volume.groupby(index.time).transform(
        lambda s: s.shift(1).rolling(lookback, min_periods=lookback).mean()
    )
    return (volume / slot_mean.replace(0.0, np.nan)).rename("slot_volume_ratio")
```
